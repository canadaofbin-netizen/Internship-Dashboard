## 5. 5대 플랫폼별 오류 방지 규칙 (Critical Rules)

1. **Workday 계정 생성 시 비밀번호 규칙**:
   - 일반 포털 비밀번호(`Jeff0825!!`, 10자리)는 12자 미만으로 거절됩니다. **반드시 `Jeff0825!!!!` (12자리)를 사용**하십시오.
2. **Workday 언어(Languages) 유창성 표시 메커니즘**:
   - Workday 폼에서 영어를 입력할 때 **"Native" 체크박스를 반드시 체크**해야 최종 Review 화면에서 **"I am fluent in this language: Yes"**로 정상 렌더링됩니다.
3. **영국 HESA 인종(Ethnicity) 분류 선택 규칙**:
   - 한국 국적 지원자는 검색 기본값인 Chinese가 아닌 **`Asian / Asian British - Any other Asian background (United Kingdom)`**를 명시적으로 선택하고 Chinese 항목은 삭제(Delete charm)해야 합니다.
4. **학위(Degree) 매칭 규칙**:
   - Workday 학위 선택 시 일반 Bachelor's가 아닌 세부 코드 **`BSc`** (Bachelor of Science)를 선택하십시오.
5. **국가 전화 코드(Country Code) 확인**:
   - 폼 기본값(미국 `+1` 등)을 방치하지 말고, 지원자의 영국 휴대전화 국가코드인 **`+44` (United Kingdom)**를 정확히 선택하십시오.
6. **지원서 텍스트 정제 의무 (Text Normalization)**:
   - PDF 자동 파싱이나 복사 시 발생하는 원시 불릿(`⚫`, `●`), 공백 누락(`⚫Engineered`), 문장 중간 임의 줄바꿈(`\n`)을 완전 제거하고 표준 규격(`• `)으로 정제 후 입력하십시오. ([Rule: Form Field Text Normalization Protocol](file:///g:/My%20Drive/Kyubin_Yun_Workspace/04_Internship/.agents/rules/form-text-normalization.md) 준수)
7. **최종 제출 절대 금지 (Zero Auto-Submit)**:
   - 지원 프로세스는 마지막 Review / Pre-submit 단계에서 멈추어야 하며, 최종 `Submit` 버튼 클릭은 금지됩니다.
